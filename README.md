# Scoosh Autos — Imperial Edition

A luxury electric vehicle showcase website featuring the Imperial Edition lineup: Cybertruck, Zeekr 8X, Zeekr 9X, and Roadster.

## Features

- Interactive car configurator with live price calculation
- Dark/light theme toggle with persistent preference
- Particle animation background with mouse interaction
- Scroll-triggered reveal animations
- Image carousel for vehicle galleries
- Reservation form with validation
- Fully responsive design
- SPA navigation (no page reloads)

## Tech Stack

- HTML5
- CSS3 (custom properties, animations)
- Vanilla JavaScript (ES6+ classes)
- Vercel (deployment)

## Getting Started

```bash
git clone https://github.com/flames778/Zeker-car-website.git
cd Zeker-car-website
```

Open `index.html` in your browser or use a local server:

```bash
npx serve .
```
